# Claim Raven Research

Free, no-account VA law and benefits reference plugin for Claude Code and Codex powered by [Claim Raven](https://claimraven.com/mcp). Connects to `https://mcp.claimraven.com/research` and reads no personal information or account data.

## Included skills

- `look-up-va-rule`: retrieve verified text from 38 CFR, 38 U.S.C., M21-1 and M21-5 with official links and confirmation dates.
- `find-va-law`: search statutes, regulations, M21 manuals, precedential court decisions and VA General Counsel opinions for a VA benefits question.
- `check-presumptive`: check PACT Act, Agent Orange, Gulf War, radiation and Camp Lejeune presumptive rules by condition or service location.
- `find-va-form`: identify the right VA form for a filing, review, statement or release, with links to VA.gov and Claim Raven's free form filler.
- `find-accredited-help`: look up free veterans service officers and VA-accredited attorneys and claims agents by state, city or ZIP code.

## Setup

Install in Claude Code:

```
/plugin install claim-raven-research --marketplace claimraven/claim-raven-plugins
```

Start asking VA law or reference questions right away. No sign-in is required; daily rate limits apply. Answers are general information, not legal or medical advice.
