# Condition theory research

Never ask for or use client names, file numbers or records.

1. Call `research_condition` for the condition with topic `service_connection`, then `rating`, `evidence` and `exam` as the question needs. Set `related_condition` for a secondary theory.
2. Use `find_va_authority` and `lookup_va_rules` for the rules behind each theory.
3. Use `study_board_decisions` to show how each theory has been granted.
4. For each theory, list the elements, the evidence that usually proves them, and the medical opinion language examiners and the Board look for.

Cite every source with its citation and date. Say plainly what you could not check.
